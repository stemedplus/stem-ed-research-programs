# Runbook: Graduate Programs

This board uses the shared STEMEd+ pipeline. For how every board works and the common fixes, see the [stemedplus-theme runbook](https://github.com/stemedplus/stemedplus-theme/blob/main/RUNBOOK.md).

| | |
|---|---|
| **Site** | stemedplus.github.io/stem-ed-research-programs |
| **Repository** | stemedplus/stem-ed-research-programs |
| **Updates** | On push (`pages.yml`); every push is validated (`validate.yml`); links checked monthly on the 3rd (`links.yml`) |
| **Listings** | One file per program in `programs/` (data CC BY 4.0) |
| **Check / build** | `python scripts/build.py --validate`, then `python scripts/build.py` |
| **Add or fix** | **Add a program** and **Update a program** issue forms, or a prefilled email from the site |

**Faculty are listed only with their agreement.** Remove or correct anyone who asks, promptly.

**Monthly link check fails:** open the run's log, fix or remove dead program links.

Permissions for the chemistry and mathematics records are in `programs/LICENSE.md` and the Source and Permissions Log.

_Written November 2026. Review with the yearly December review._
